Airbnb NYC Data Analysis & Interactive Dashboard

Project Overview

This project focuses on analyzing Airbnb listings in New York City to understand the rental market, pricing trends, room types, and host performance.

The goal is to transform raw data into meaningful insights through data analysis and interactive visualizations using Power BI.

Dataset

The dataset contains 48,884 records and 15 columns, including:

- Listing Name
- Host ID
- Neighborhood and Neighborhood Group
- Latitude and Longitude
- Room Type
- Price
- Minimum Nights
- Number of Reviews
- Reviews per Month
- Availability (365 days)

Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization

Dashboard Structure

1. Market Overview

- Total Listings
- Average Price
- Total Reviews
- Listings distribution by location
- Room type distribution

2. Pricing & Strategy

- Average price by neighborhood and room type
- Pricing analysis by stay category
- Price vs. availability analysis

3. Host Performance & Demand

- Host listing performance
- Top hosts analysis
- Demand and availability indicators

Key Objectives

- Understand Airbnb market distribution across NYC.
- Identify pricing patterns across neighborhoods.
- Compare different room types.
- Evaluate host performance and listing availability.

Project Outcome

An interactive Power BI dashboard that helps explore the NYC Airbnb market and identify patterns that support better business understanding and decision-making.
